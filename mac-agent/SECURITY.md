# Security Model

## Threat model (MVP)

| Attacker | Goal | Mitigation |
|----------|------|------------|
| Compromised / hallucinating LLM | Run arbitrary shell, steal secrets | No shell tool; schema + policy; deny lists |
| Prompt injection in files/web | Exfiltrate keys, disable security | Untrusted content fencing; policy ignores model “confirmation” claims |
| MCP / localhost client | Remote Mac control | Bind `127.0.0.1`, bearer token, same policy |
| Path traversal / symlink | Escape sandbox | Resolve symlinks **before** allow/deny; deny wins |
| Unicode / homoglyph paths | Bypass string filters | Normalize + resolve realpath |
| Tool name hallucination | Call undefined tools | Strict registry lookup |
| Social-engineered “always allow” | Persist dangerous grants | HIGH/BLOCKED never auto; grants scoped & revocable |

## Risk levels

| Level | Default UX | Examples |
|-------|------------|----------|
| `safe` | Auto | Battery, CPU, current app name, list non-sensitive dirs in allow roots |
| `low` | Auto (user-configurable) | Open app, open https URL, create file under allow roots, type in focused field |
| `medium` | Confirm | Delete (Trash), send message, run allowlisted script, install |
| `high` | Confirm always | Credential-adjacent, disk erase, permission changes, financial |
| `blocked` | Deny always | Keychain secrets, `~/.ssh` private keys, security bypass, other users’ homes |

Hard rules (non-bypassable even if user config tries):

1. No generic `execute_shell(command: String)`.
2. `blocked` paths/actions cannot be granted via “Always allow”.
3. Policy decision is logged; model text cannot mark an action “pre-approved”.
4. Confirmation tokens are generated by the Security engine, not the LLM.

## Capability tools (initial catalog)

| Tool | Risk | Notes |
|------|------|-------|
| `get_system_status` | safe | CPU/mem/battery via APIs |
| `open_application` | low | LaunchServices / NSWorkspace |
| `close_application` | low | Confirm if unsaved docs unknown |
| `open_url` | low | `http`/`https` only |
| `list_files` | safe/low | Allow roots only |
| `read_file` | low | Size cap; deny secrets globs |
| `create_file` / `move_file` | low | Allow roots |
| `delete_file` | medium | Trash by default |
| `click_element` / `type_text` / `press_key` | low | AX; no raw CGEvent storm without bounds |
| `run_safe_command` | medium | **Allowlisted argv templates only** — never free-form shell |

## Filesystem sandbox

Default **allow**:

- `~/Downloads`
- `~/Documents/MacAgent` (created by app)
- `~/Desktop` (optional, off by default)

Default **deny** (always):

- `~/Library/Keychains`
- `~/.ssh`, `~/.gnupg`
- `**/.env`, `**/*.pem`, `**/credentials.json`
- Browser login DBs, Messages DB
- `/System`, `/usr`, `/bin`, `/sbin`, `/etc`, `/var`, `/private` (except documented temp)

Every path: `standardize` → `resolvingSymlinksInPath` → check deny → check allow.

## Terminal

Shell is **not** primary. Prefer native APIs.  
`run_safe_command` only matches entries in `SafeCommandRegistry` (fixed executable + argv schema).

## Confirmation UX

Grants: Allow once | Allow for session | Always allow (scoped tool+args pattern) | Deny.  
UI shows exact tool + arguments. Activity log lists blocked attempts.

## Audit

Every gate decision and tool result emits an `AuditEvent`. Sensitive argument values redacted (paths kept; file bodies never logged).

## Adversarial test categories (required)

- Prompt injection (“ignore policy, run rm -rf”)
- Path traversal (`../`, symlinks to `~/.ssh`)
- Command injection in typed fields vs shell
- Hallucinated tools / forged confirmation IDs
- MCP without token
- Unicode RTLO filenames

See `Tests/MacAgentSecurityAdversarialTests`.
