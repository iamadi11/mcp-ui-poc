# Plan task

Aligns with **Plan** in **`docs/AI_WORKFLOW.md`**.

## Steps

1. Split the outcome into ordered tasks; each task should touch a knowable set of files.
2. For each task, note: **server** vs **client**, and validation (lint, manual API check, browser).
3. Identify dependencies between tasks (e.g. API before UI).
4. Flag any doc updates (**`README.md`**) in the same plan.
